# VibeMap v0.2 — макеты экранов прототипа

Каркас UX/UI прототипа **VibeMap v0.2** — вайб-социальной сети с внутренним
ИИ-консьержем Волли.

## Что здесь

- `vibemap-v0.2-screens.html` — галерея из 14 визуалов: карта архитектуры
  продукта + 13 экранов кликабельного прототипа. Открыть в браузере, один файл,
  без сборки и зависимостей (иконки Tabler подгружаются с CDN).

## Экраны

**Пиллар 1 — Волли + каталоги:** навигация и поверхность Волли · Волли-чат
(голос) · шит брони · каталог-обзор (Волли-фильтр) · каталог отфильтрован ·
карточка места.

**Пиллар 2 — социальное:** знакомства · профиль друга · друзья · приглашения ·
подарок билета.

**Эволюция из v0.1:** «Я» · «Лента».

## Источник истины

Полный текстовый UX/UI-спек (все экраны, решённые форки, единый язык
интерфейса) — в `claude_state`, decision `related_to='ux-design'`,
`project_slug='vibemap'`. Эти макеты — визуальный референс к нему.

Дизайн-токены — `docs/aurora-tokens.md` (расширяется при консолидации Aurora
перед сборкой).

## Граница прототипа

Реально строится: ИИ-консьерж Волли (разговор, агентность, голос через Yandex
SpeechKit), весь UI, социальный граф (друзья / приглашения / подарки —
таблицы + UI). Симулируется: данные каталогов, брони, подарки билетов — без
реальных денег и внешних вендоров.

## Стадия

Дизайн-фаза завершена. Дальше: консолидация Aurora → сборка на ветке
`proto/usp`, прототип-темпом, пиллар 1 → пиллар 2. Ветка `main` остаётся
стабильной (`v0.1.4-account`).
